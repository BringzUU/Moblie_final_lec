1. RESTful API กับ HTTP Method

REST API คือการสื่อสารระหว่างแอป (client) กับ backend ผ่าน HTTP โดยแต่ละ method แทนการกระทำต่อข้อมูล (CRUD)

HTTP MethodCRUDใช้ทำอะไรStatus ที่สำเร็จ
GETReadอ่าน/ดึงข้อมูล200
POSTCreateสร้างข้อมูลใหม่201
PUTUpdateแก้ไขข้อมูล (ระบุ id ใน URL)200
DELETEDeleteลบข้อมูล (ระบุ id ใน URL)200

4. Flutter HTTP: GET / POST / PUT / DELETE

ใช้ package:http คู่กับ dart:convert (jsonDecode / jsonEncode) ทุกฟังก์ชันเป็น async + await และครอบ try/catch

GET (Read)

Future<void> fetchData() async {
  try {
    var response = await http.get(Uri.parse('http://localhost:3000/products'));
    if (response.statusCode == 200) {
      List<dynamic> jsonList = jsonDecode(response.body);
      // code something...
    } else {
      throw Exception("Failed to load products");
    }
  } catch (e) { print(e); }
}

POST (Create) – ต้องมี header + body เป็น JSON

Future<void> createProduct() async {
  try {
    var response = await http.post(
      Uri.parse("http://localhost:3000/products"),
      headers: {"Content-Type": "application/json"},
      body: jsonEncode({
        "name": "iPhone 5s",
        "description": "Apple smartphone",
        "price": 21999.00
      }));
    if (response.statusCode == 201) {   // สร้างสำเร็จ = 201
      // code something...
    } else { throw Exception("Failed to create product"); }
  } catch (e) { print(e); }
}

PUT (Update) – ระบุ id ท้าย URL

Future<void> updateProduct({dynamic idUpdate = "44b7"}) async {
  try {
    var response = await http.put(
      Uri.parse("http://localhost:3000/products/$idUpdate"),
      headers: {"Content-Type": "application/json"},
      body: jsonEncode({
        "name": "iPhone 5 plus",
        "description": "Apple smartphone",
        "price": 34900.00
      }));
    if (response.statusCode == 200) { /* code something... */ }
    else { throw Exception("Failed to update product"); }
  } catch (e) { print(e); }
}

DELETE

Future<void> deleteProduct({dynamic idDelete = "44b7"}) async {
  try {
    var response = await http
        .delete(Uri.parse("http://localhost:3000/products/$idDelete"));
    if (response.statusCode == 200) { /* code something... */ }
    else { throw Exception("Failed to delete products"); }
  } catch (e) { print(e); }
}
จุดที่ออกข้อสอบบ่อย: POST สำเร็จ = 201 (ไม่ใช่ 200) · POST/PUT ต้องใส่ Content-Type: application/json และ jsonEncode body · GET ใช้ jsonDecode(response.body)

6. Firebase

Firebase = แพลตฟอร์มพัฒนาแอปครบวงจร (Mobile & Web) สร้างโดย Firebase Inc. ปัจจุบันอยู่ภายใต้ Google ให้บริการแบบ BaaS (Backend as a Service) คือไม่ต้องสร้างเซิร์ฟเวอร์/เขียน backend เอง

Cloud Firestore = ฐานข้อมูล NoSQL บน Cloud อ่าน/เขียนแบบ เรียลไทม์ และซิงค์ข้อมูลระหว่างอุปกรณ์ เหมาะกับข้อมูล JSON-based

ขั้นตอน Set up

  1. สร้างโปรเจกต์ที่ firebase.google.com → ตั้งชื่อ → ตั้งค่า Analytics
  2. เปิดใช้ Firestore Database → สร้าง Collection / Document ตัวอย่าง → ตั้ง Rules ให้ allow read, write (สำหรับทดสอบ)
  3. เลือก Add app → Android → copy package id จาก android/app/build.gradle
  4. เพิ่ม plugin com.google.gms.google-services ใน android/app/build.gradle
  5. ติดตั้ง CLI และ config ตามคำสั่งด้านล่าง
npm i -g firebase-tools                      # Firebase CLI (ต้องมี Node)
firebase login                               # ล็อกอิน
firebase projects:list                       # ดูโปรเจกต์ทั้งหมด
dart pub global activate flutterfire_cli     # ติดตั้ง flutterfire_cli
flutterfire -v                               # เช็คว่าใช้ได้ (ถ้าได้ ข้ามการตั้ง PATH)
flutterfire configure --platforms=android,ios,web   # เลือกโปรเจกต์ที่จะใช้
flutter pub add cloud_firestore
flutter pub add firebase_core
// android/app/build.gradle
plugins {
    id "com.android.application"
    id "kotlin-android"
    id "dev.flutter.flutter-gradle-plugin"
    id "com.google.gms.google-services"   // เพิ่ม plugin นี้
}

7. Firestore CRUD ใน Flutter

Read (Stream – เรียลไทม์)

final CollectionReference products =
    FirebaseFirestore.instance.collection('products');

@override
Widget build(BuildContext context) {
  return Scaffold(
    body: StreamBuilder<QuerySnapshot>(
      stream: products.snapshots(),
      builder: (context, snapshot) {
        if (!snapshot.hasData) return const CircularProgressIndicator();
        final data = snapshot.data!.docs;
        return ListView.separated(
          separatorBuilder: (context, index) => const Divider(),
          itemCount: data.length,
          itemBuilder: (context, index) {
            final product = data[index];
            String productId = product.id;   // ID ของ document
            return ListTile(
              leading: Text(productId),
              title: Text(product['name']),
              subtitle: Text(product['description']),
            );
          },
        );
      },
    ),
  );
}

Create / Update / Delete

// CREATE
Future<void> createProduct(String name, String description, double price) async {
  await products.add({'name': name, 'description': description, 'price': price});
}
// UPDATE
Future<void> updateProduct(String docId, String name, String description, double price) async {
  await products.doc(docId).update({'name': name, 'description': description, 'price': price});
}
// DELETE
Future<void> deleteProduct(String docId) async {
  await products.doc(docId).delete();
}

8. ข้อสอบจำลอง (กดดูเฉลย)

1) HTTP method ใดใช้สร้างข้อมูลใหม่ และ status code ที่สำเร็จคืออะไร?

POST, 201

2) Android Emulator เรียก API บนเครื่องตัวเองต้องใช้ host อะไร ทำไม?

10.0.2.2 เพราะ localhost ใน emulator หมายถึงตัว emulator เอง ไม่ใช่คอมพิวเตอร์ที่รัน API

3) Firebase เป็นบริการประเภทใด?

BaaS (Backend as a Service) ไม่ต้องสร้างเซิร์ฟเวอร์เอง

4) Cloud Firestore เป็นฐานข้อมูลแบบใด และเหมาะกับงานอะไร?

NoSQL บน Cloud เหมาะกับข้อมูลเรียลไทม์และข้อมูลแบบ JSON

5) คำสั่งใดตั้งค่า Firebase ให้โปรเจกต์ Flutter?

flutterfire configure (ติดตั้งผ่าน dart pub global activate flutterfire_cli)

6) ต้องทำอะไรใน main() ก่อนใช้ Firebase?

WidgetsFlutterBinding.ensureInitialized() แล้ว await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform)

7) Widget ใดอ่านข้อมูล Firestore แบบเรียลไทม์? ดึง id ของ document อย่างไร?

StreamBuilder กับ collection.snapshots() · ใช้ doc.id

8) (อัตนัย) อธิบายขั้นตอนทำหน้าลบสินค้าให้ปลอดภัย

กดปุ่มลบ → แสดง AlertDialog ยืนยัน → ถ้ากด OK เรียก http.delete(.../products/$id) (หรือ doc(id).delete()) → ตรวจ statusCode == 200 → แสดง SnackBar สำเร็จ → โหลดรายการใหม่
