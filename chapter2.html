บทที่ 2: Widgets

Widget พื้นฐาน, Layout, Button, Image, ListView, Stateless / Stateful และ Lifecycle

Widget คืออะไร Widget Tree MaterialApp Scaffold Text Container / SizedBox Row / Column Expanded Stack / Positioned Button Image ListView Stateless / Stateful Lifecycle โจทย์ Exercise ทวนก่อนสอบ

1. Widget คืออะไร

Widget คือองค์ประกอบพื้นฐาน (building block) ของหน้าจอ/UI ทั้งหมดใน Flutter — ข้อความ ปุ่ม รูปภาพ ไอคอน หรือแม้แต่โครงสร้างหน้า (Layout) ก็เป็น Widget ทั้งหมด
กลุ่ม Widgetหน้าที่ตัวอย่าง
Scaffoldโครงสร้างหลักของหน้าจอScaffold, AppBar
Textแสดงข้อความText
Layoutจัดเรียงตำแหน่งRow, Column, Container, Stack
Buttonโต้ตอบกับผู้ใช้ElevatedButton, TextButton
ImageแสดงภาพImage.network, Image.asset

2. Widget Tree

การนำ Widget มาซ้อนกันเป็นแผนผังต้นไม้ Widget ที่บรรจุ Widget อื่นเรียกว่า Parent ส่วน Widget ที่อยู่ข้างในเรียกว่า Child

3. MaterialApp

Widget ระดับสูงสุดสำหรับสร้างแอปที่ใช้ Material Design (แนวทางออกแบบของ Google) เป็นจุดเริ่มต้นของแอป

หน้าที่ของ MaterialApp
  1. เป็นโครงสร้างพื้นฐาน/จุดเริ่มต้นของแอป Material Design
  2. กำหนดธีม — ThemeData เช่น สี ตัวอักษร
  3. จัดการเส้นทาง (Routing) — กำหนด routes และการนำทาง
  4. กำหนดภาษาและทิศทางข้อความ — locale, textDirection
@override
Widget build(BuildContext context) {
  return MaterialApp(
    title: 'Flutter Demo',
    debugShowCheckedModeBanner: false,   // ซ่อนป้าย DEBUG
    theme: ThemeData(useMaterial3: true, primarySwatch: Colors.blue),
    home: const HomeScreenApp(),         // หน้าแรกของแอป
  );
}

4. Scaffold

โครงสร้างพื้นฐานของหน้าจอ ช่วยสร้าง UI ได้ง่าย รองรับ AppBar, Drawer, FloatingActionButton, BottomNavigationBar และ body

return Scaffold(
  appBar: AppBar(title: const Text('My App')),
  body: const Center(child: Text('Hello, World!')),
);

5. Text Widget

แสดงข้อความบนหน้าจอ กำหนดสี ขนาด ฟอนต์ การจัดตำแหน่ง ได้ผ่าน style: TextStyle(...)

return const Scaffold(
  body: Center(
    child: Text(
      'Hello, Flutter',
      style: TextStyle(fontSize: 24),
    ),
  ),
);

6. Container และ SizedBox

Container

Widget อเนกประสงค์ ใช้จัดวาง ตกแต่ง หรือห่อหุ้ม Widget อื่น กำหนดขนาด สีพื้นหลัง ขอบ มุมโค้ง และการจัดตำแหน่งภายในได้หลากหลาย

Container(
  width: 100,
  height: 100,
  color: Colors.red,
)

SizedBox

กำหนดขนาด (width, height) ของพื้นที่ หรือใช้สร้างช่องว่างระหว่าง Widget

  1. กำหนดขนาดที่แน่นอนให้ Widget
  2. สร้างพื้นที่ว่าง (space) ระหว่าง Widget
  3. ใช้เป็นตัวปรับระยะ (Spacer) ใน Layout
💡 Container vs SizedBox: SizedBox คล้าย Container แต่เป็น "กล่องเปล่า ๆ" ที่มีไว้กำหนดขนาด/ช่องว่างเท่านั้น (ไม่มีสี/ขอบ/การตกแต่ง) ถ้าต้องการแค่เว้นระยะให้ใช้ SizedBox
Row(children: [
  Container(width: 50, height: 50, color: Colors.red),
  const SizedBox(width: 20),              // เว้นระยะแนวนอน 20
  Container(width: 50, height: 50, color: Colors.blue),
])

7. Row และ Column

RowColumn
ทิศทางแนวนอน (Horizontal) ซ้าย → ขวาแนวตั้ง (Vertical) บน → ล่าง
แกนหลัก (main axis)แนวนอนแนวตั้ง
แกนรอง (cross axis)แนวตั้งแนวนอน
รับ childchildren: [ ... ] (เป็น List) ใช้คู่กับ mainAxisAlignment และ crossAxisAlignment
Row(
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    Container(height: 100, width: 100, color: Colors.blue),
    Container(height: 100, width: 100, color: Colors.red),
  ],
)

Column(
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    Container(height: 100, width: 100, color: Colors.blue),
    Container(height: 100, width: 100, color: Colors.red),
  ],
)

Axis Alignment

ค่าความหมาย
startชิดต้นแกน
endชิดท้ายแกน
centerกึ่งกลาง
spaceBetweenตัวแรก/ตัวสุดท้ายชิดขอบ ช่องว่างเท่ากันระหว่างตัว
spaceAroundช่องว่างรอบแต่ละตัวเท่ากัน (ขอบเป็นครึ่งหนึ่ง)
spaceEvenlyช่องว่างทุกช่องเท่ากันหมด รวมขอบ

crossAxisAlignment ใช้ค่า start, end, center, stretch, baseline จัดตำแหน่งตามแกนรอง

ข้อจำกัดของ Row / Column
  • ถ้า Widget มากเกินขอบจอ (แนวนอนหรือแนวตั้ง) ต้องห่อด้วย SingleChildScrollView พร้อม scrollDirection: Axis.horizontal หรือ Axis.vertical
  • ลูกของ Row/Column ขยายพื้นที่เองไม่ได้ ต้องใช้ Expanded หรือ Flexible ช่วย

8. Expanded

ใช้ภายใน Row/Column เพื่อขยาย child ให้เต็มพื้นที่ที่เหลือตามแกนหลัก ถ้ามีหลาย Expanded จะแบ่งพื้นที่ตามสัดส่วน flex

Row(
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    Container(height: 100, width: 100, color: Colors.blue),
    Expanded(child: Container(height: 100, color: Colors.red)),   // กินที่ที่เหลือทั้งหมด
  ],
)

// แบ่งสัดส่วน 1 : 2
Row(children: [
  Expanded(flex: 1, child: Container(height: 100, color: Colors.green)),
  Expanded(flex: 2, child: Container(height: 100, color: Colors.orange)),
])

9. Stack และ Positioned

Stack

Layout ที่ซ้อน Widget หลายตัวทับกัน (เหมือนเลเยอร์ภาพ) ตัวแรกอยู่ล่างสุด ตัวถัดไปซ้อนด้านบน ถ้าไม่ใช้ Positioned ลูกจะจัดตำแหน่งตาม alignment ของ Stack

Stack(
  children: [
    Container(width: 200, height: 200, color: Colors.blue),
    Container(width: 150, height: 150, color: Colors.green),
    Container(width: 100, height: 100, color: Colors.red),
  ],
)

Positioned

กำหนดตำแหน่งของ child ภายใน Stack โดยระบุระยะจาก top, left, right, bottom — ต้องใช้คู่กับ Stack เท่านั้น เหมาะกับ badge แจ้งเตือน ไอคอนบนภาพ UI ซ้อนหลายชั้น

Stack(
  children: [
    Container(width: 200, height: 200, color: Colors.blue),
    Positioned(
      top: 10,
      right: 10,
      child: Container(width: 40, height: 40, color: Colors.red),
    ),
    Positioned(
      bottom: 0,
      left: 0,
      child: Container(width: 60, height: 60, color: Colors.green),
    ),
  ],
)

10. Button Widgets

ElevatedButtonTextButton
หน้าตานูนขึ้นจากพื้นหลัง มีพื้นหลังและเงา (elevation)ข้อความเรียบ ๆ ไม่มีพื้นหลัง ไม่มีกรอบ (borderless)
ใช้กับการกระทำหลัก เช่น "บันทึก", "ยืนยัน", "ส่งข้อมูล"การกระทำรอง เช่น "ลืมรหัสผ่าน?", "ยกเลิก", "เรียนรู้เพิ่มเติม"
อื่น ๆต้องมี onPressed (ฟังก์ชันที่ทำงานเมื่อกด) และ child · TextButton เปลี่ยนสีเมื่อกด/hover ตามธีม
ElevatedButton(
  onPressed: () {
    print('Button Pressed');
  },
  child: const Text('Click Me'),
)

TextButton(
  onPressed: () {
    print('Text Button Pressed');
  },
  child: const Text('Click Me'),
)
ถ้า onPressed: null ปุ่มจะถูก disable (สีเทา กดไม่ได้)

11. Image Widgets

Image.network — โหลดภาพจาก URL

เหมาะกับรูปจากเว็บ เช่น โปรไฟล์ผู้ใช้ แบนเนอร์ ภาพสินค้า (ต้องมีอินเทอร์เน็ต)

Image.network(
  'https://www.google.com/images/branding/googlelogo/2x/googlelogo_color_272x92dp.png',
  width: 100,
  height: 100,
)

Image.asset — ภาพจากไฟล์ในแอป

เหมาะกับภาพที่เตรียมไว้ล่วงหน้า เช่น โลโก้ ไอคอน แบนเนอร์ในแอป

ขั้นตอนการใช้ asset
  1. สร้างโฟลเดอร์ assets ระดับเดียวกับโฟลเดอร์ lib
  2. ใส่ไฟล์ภาพลงไป เช่น assets/pikachu.png
  3. ประกาศ path ใน pubspec.yaml
  4. เรียกใช้ด้วย Image.asset('path')
flutter:
  assets:
    - assets/          # ระวัง: เยื้อง (indent) ต้องถูกต้อง
Image.asset(
  'assets/pikachu.png',
  width: 100,
  height: 100,
)
หลังแก้ pubspec.yaml ต้องรัน flutter pub get (หรือ restart แอป) ถึงจะเห็นผล

12. ListView

Widget แสดงรายการ Widget หลายตัวแบบ เลื่อนได้ (scrollable) เหมาะกับรายการยาว เช่น รายการสินค้า แชท เมนู

ชนิดใช้เมื่อ
ListView(children: [...])รายการน้อย ๆ ที่รู้จำนวนแน่นอน
ListView.builderข้อมูลจำนวนมาก หรือสร้างรายการแบบไดนามิกตามตำแหน่ง (สร้างเฉพาะ item ที่มองเห็น)
ListView.separatedต้องมีตัวคั่น (divider) ระหว่างแต่ละรายการ
// ListView ปกติ
ListView(
  children: [
    Container(height: 350, width: double.infinity, color: Colors.grey,   child: const Text('Item 1')),
    Container(height: 350, width: double.infinity, color: Colors.red,    child: const Text('Item 2')),
    Container(height: 350, width: double.infinity, color: Colors.yellow, child: const Text('Item 3')),
  ],
)

// ListView.builder
ListView.builder(
  itemCount: 20,
  itemBuilder: (context, index) {
    return ListTile(
      title: Text('Item $index'),
    );
  },
)

// ListView.separated
ListView.separated(
  itemCount: 15,
  itemBuilder: (context, index) {
    return Text('Item $index');
  },
  separatorBuilder: (context, index) {
    return const Divider();
  },
)

// ListView แนวนอน
ListView(
  padding: const EdgeInsets.all(10),
  scrollDirection: Axis.horizontal,
  shrinkWrap: true,
  children: [
    Container(width: 300, color: Colors.red),
    Container(width: 300, color: Colors.green),
    Container(width: 300, color: Colors.blue),
  ],
)
itemCount = จำนวนรายการ · itemBuilder = ฟังก์ชันสร้างแต่ละ item (รับ context, index) · separatorBuilder = สร้างตัวคั่น · scrollDirection: Axis.horizontal = เลื่อนแนวนอน

13. Stateless vs Stateful Widget

StatelessWidgetStatefulWidget
UI หลังสร้างไม่เปลี่ยนแปลงเปลี่ยนได้เมื่อ State เปลี่ยน
เหมาะกับUI คงที่ เช่น ข้อความ รูปภาพ ปุ่มที่ไม่เปลี่ยนInteractive เช่น ปุ่มกดแล้วเปลี่ยนสี, Counter
โครงสร้าง1 class (build)2 class: Widget + State (createState)
อัปเดต UI—เรียก setState()

Stateless

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(useMaterial3: true),
      home: const GreetingWidget(name: 'Elon musk'),
    );
  }
}

class GreetingWidget extends StatelessWidget {
  final String name;
  const GreetingWidget({super.key, required this.name});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Text('Hello, $name', style: const TextStyle(fontSize: 24)),
      ),
    );
  }
}

Stateful (Counter)

import 'package:flutter/material.dart';

class MyStateful extends StatefulWidget {
  const MyStateful({super.key});

  @override
  State<MyStateful> createState() => _MyStatefulState();
}

class _MyStatefulState extends State<MyStateful> {
  int counter = 0;                       // ← State (ข้อมูลที่เปลี่ยนได้)

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("StatefulWidget")),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text("Counter: $counter"),
            ElevatedButton(
              onPressed: () {
                setState(() {            // แจ้ง Flutter ให้ build ใหม่
                  counter++;
                });
              },
              child: const Text("+ Increment"),
            ),
          ],
        ),
      ),
    );
  }
}
✅ ถ้าแก้ตัวแปรโดยไม่เรียก setState() ค่าตัวแปรเปลี่ยนจริง แต่หน้าจอจะไม่อัปเดต

14. Lifecycle ของ StatefulWidget

เมธอดเรียกเมื่อใช้ทำอะไร
createState()สร้าง StatefulWidget (ครั้งเดียวตอนเริ่ม)สร้าง State Object
initState()ครั้งเดียวตอน State ถูกสร้างตั้งค่าเริ่มต้น ตัวแปร subscribe event โหลดข้อมูล · ต้องเรียก super.initState() เสมอ
didChangeDependencies()InheritedWidget/Context เปลี่ยน เช่น Theme, Localizationเรียกได้หลายครั้งใน Lifecycle
build()State สร้างครั้งแรก หรือมีการเปลี่ยนแปลงที่กระทบ UIสร้าง UI (เรียกทุกครั้งที่ State เปลี่ยน)
didUpdateWidget()Widget เดิมที่สร้าง State ถูกเปลี่ยน เช่น ส่งค่าใหม่ผ่าน Constructorตรวจสอบค่าที่เปลี่ยน
deactivate()State ถูกถอดออกจาก Widget Tree—
dispose()ครั้งสุดท้ายก่อน State ถูกทำลายล้างข้อมูล ยกเลิก Event ปิด Stream · ต้องเรียก super.dispose()
setState()เรียกเองแจ้ง Flutter ว่า State เปลี่ยน ให้สร้าง UI ใหม่ — ไม่ใช่ Lifecycle แต่สำคัญ
⚠️ สไลด์อาจเขียนคำอธิบายของ deactivate() ซ้ำกับ didChangeDependencies() — ในความเป็นจริง deactivate() เรียกเมื่อ State ถูกถอดจาก tree ก่อน dispose() ตอนสอบจำลำดับให้ถูกก็พอ
class _MyState extends State<MyWidget> {
  @override
  void initState() {
    super.initState();      // ต้องเรียกก่อน
    // ตั้งค่าเริ่มต้น / โหลดข้อมูล
  }

  @override
  Widget build(BuildContext context) {
    return const Text('Hello');
  }

  @override
  void dispose() {
    // ล้างข้อมูล / ยกเลิก subscribe
    super.dispose();        // ต้องเรียกท้ายสุด
  }
}

Exercise III — ไฟจราจร

Stack เป็นโครงหลัก · กรอบตู้สีดำ 120×300 · ไฟ 3 ดวง (แดง เหลือง เขียว) วงกลม 80×80 · ใช้ Positioned เรียงบนลงล่างห่างเท่ากัน · จัดกึ่งกลางหน้าจอ
Hint: ครอบ Stack ด้วย Align หรือ Center
💡 คำนวณระยะห่าง: ความสูง 300 − (80 × 3) = 60 → แบ่ง 4 ช่อง ช่องละ 15 → top = 15, 110, 205 · แนวนอน (120 − 80) / 2 = 20 → left: 20
ดูเฉลย 
Center(
  child: SizedBox(
    width: 120,
    height: 300,
    child: Stack(
      children: [
        Container(color: Colors.black),            // กรอบตู้ไฟ
        Positioned(
          top: 15, left: 20,
          child: Container(
            width: 80, height: 80,
            decoration: const BoxDecoration(color: Colors.red, shape: BoxShape.circle),
          ),
        ),
        Positioned(
          top: 110, left: 20,
          child: Container(
            width: 80, height: 80,
            decoration: const BoxDecoration(color: Colors.yellow, shape: BoxShape.circle),
          ),
        ),
        Positioned(
          top: 205, left: 20,
          child: Container(
            width: 80, height: 80,
            decoration: const BoxDecoration(color: Colors.green, shape: BoxShape.circle),
          ),
        ),
      ],
    ),
  ),
)
⚠️ ถ้าใช้ shape: BoxShape.circle ห้ามใส่ color: ตรง ๆ ใน Container พร้อม decoration — ต้องใส่สีใน BoxDecoration (ไม่งั้น error)

16. ทวนก่อนสอบ

Widget คืออะไร?องค์ประกอบพื้นฐานของ UI ทุกอย่างในแอป Flutter
Parent กับ Child Widget ต่างกันอย่างไร?Parent คือ Widget ที่บรรจุ Widget อื่นไว้ข้างใน Child คือ Widget ที่อยู่ข้างใน
MaterialApp ทำหน้าที่อะไรบ้าง (4 ข้อ)?โครงสร้างพื้นฐานของแอป · กำหนดธีม · จัดการ Routing · กำหนดภาษา/ทิศทางข้อความ
Row กับ Column ต่างกันอย่างไร?Row จัดแนวนอน (ซ้าย→ขวา) Column จัดแนวตั้ง (บน→ล่าง) ทั้งคู่รับ children เป็น List
SizedBox กับ Container ต่างกันอย่างไร?SizedBox กำหนดขนาด/ช่องว่างเท่านั้น (กล่องเปล่า) Container ตกแต่งได้ (สี ขอบ มุมโค้ง padding ฯลฯ)
Expanded ใช้ทำอะไร และใช้ที่ไหนได้?ขยาย child ให้เต็มพื้นที่ที่เหลือตามแกนหลัก ใช้ภายใน Row/Column เท่านั้น แบ่งสัดส่วนด้วย flex
Positioned ใช้ที่ไหน?ใช้ภายใน Stack เท่านั้น กำหนดตำแหน่งด้วย top, left, right, bottom
ElevatedButton กับ TextButton ต่างกันอย่างไร?ElevatedButton มีพื้นหลังและเงานูน ใช้กับการกระทำหลัก · TextButton เป็นข้อความเรียบ ๆ ไม่มีพื้นหลัง/กรอบ ใช้กับการกระทำรอง
Image.network กับ Image.asset ต่างกันอย่างไร?network โหลดภาพจาก URL บนอินเทอร์เน็ต · asset ใช้ภาพจากไฟล์ในแอป ต้องสร้างโฟลเดอร์ assets และประกาศ path ใน pubspec.yaml
ListView.builder ใช้เมื่อไหร่? ListView.separated ต่างกันอย่างไร?builder ใช้เมื่อข้อมูลมาก/สร้างแบบไดนามิก · separated เหมือน builder แต่มี separatorBuilder สำหรับตัวคั่น (เช่น Divider)
Stateless กับ Stateful ต่างกันอย่างไร?Stateless UI ไม่เปลี่ยนหลังสร้าง · Stateful UI เปลี่ยนได้เมื่อ State เปลี่ยน ใช้ setState() อัปเดต
ลำดับ Lifecycle ของ StatefulWidget?createState → initState → didChangeDependencies → build → (didUpdateWidget / setState → build ซ้ำ) → deactivate → dispose
initState() และ dispose() ต้องเรียกอะไรเสมอ?super.initState() และ super.dispose()
setState() เป็น Lifecycle หรือไม่?ไม่ใช่ Lifecycle แต่เป็นฟังก์ชันสำคัญที่แจ้ง Flutter ว่า State เปลี่ยนและต้อง build UI ใหม่
ถ้า Row มี Widget เกินขอบจอ แก้อย่างไร?ห่อด้วย SingleChildScrollView พร้อม scrollDirection: Axis.horizontal
