1. Form คืออะไร

Form คือองค์ประกอบที่ช่วยให้ผู้ใช้ โต้ตอบ (Interact) กับระบบได้ โดยเป็นการป้อนข้อมูลเข้าสู่ระบบ (Input) เช่น ลงทะเบียน เข้าสู่ระบบ บันทึกข้อมูล
Widgetหน้าที่
TextFormFieldช่องกรอกข้อความ (ชื่อ อีเมล รหัสผ่าน) มี validator ตรวจสอบค่า
Formตัวจัดการฟอร์มทั้งหมด ครอบ TextFormField หลายช่อง ใช้ GlobalKey<FormState> ตรวจสอบ/บันทึกค่า
TextEditingControllerเก็บ/ดึง/อัปเดตค่าในช่องกรอก
DropdownButtonFormFieldเลือกค่าจากรายการ (Drop down) รองรับ validator
CheckboxListTileเลือก true/false (Boolean) เลือกได้หลายตัว
RadioListTileเลือกได้ เพียงตัวเดียว จากหลายตัวเลือก เช่น เพศ
SwitchListTileสลับ ON/OFF เช่น เปิด/ปิดการแจ้งเตือน

2. TextFormField

ช่องกรอกข้อความ ใช้ decoration ตกแต่ง, validator ตรวจสอบ, onChanged รับค่าทุกครั้งที่พิมพ์

TextFormField(
  decoration: const InputDecoration(labelText: 'Name'),
  validator: (value) {
    if (value == null || value.isEmpty) {
      return 'Please enter your name';   // คืน String = ไม่ผ่าน (แสดง error)
    }
    return null;                         // คืน null = ผ่าน
  },
  onChanged: (value) {
    print(value);
  },
)
จำให้ได้: validator ถ้าผ่าน → return null · ถ้าไม่ผ่าน → return ข้อความ error (String)

ตกแต่งกรอบ (InputDecoration)

TextFormField(
  controller: _nameController,
  decoration: const InputDecoration(
    prefixIcon: Icon(Icons.person),                 // ไอคอนหน้าช่อง
    hintText: 'Name',                               // ข้อความจาง ๆ
    border: OutlineInputBorder(
      borderRadius: BorderRadius.all(Radius.circular(15)),  // มุมโค้ง
    ),
    focusedBorder: OutlineInputBorder(
      borderSide: BorderSide(width: 2.0),           // ขอบหนาตอนโฟกัส
    ),
  ),
  validator: (value) {
    if (value == null || value.isEmpty) {
      return 'Please enter your name';
    }
    return null;
  },
)
Propertyใช้ทำอะไร
labelText / hintTextป้ายชื่อช่อง / ข้อความแนะนำ
prefixIconไอคอนด้านหน้า

keyboardTypeชนิดแป้นพิมพ์ เช่น TextInputType.number
obscureText: trueซ่อนข้อความ (รหัสผ่าน)

3. Form + GlobalKey<FormState>

ครอบ TextFormField หลายช่องด้วย Form แล้วผูก key กับ GlobalKey<FormState> เพื่อเรียก validate() ตรวจทุกช่องพร้อมกัน

class _MyWidgetState extends State<MyWidget> {
  final _formKey = GlobalKey<FormState>();      // 1. สร้าง key

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Simple Form')),
      body: Form(
        key: _formKey,                           // 2. ผูก key กับ Form
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            TextFormField(
              decoration: const InputDecoration(labelText: 'Name'),
              validator: (value) {
                if (value == null || value.isEmpty) {
                  return 'Please enter your name';
                }
                return null;
              },
            ),
            TextFormField(
              decoration: const InputDecoration(labelText: 'Email'),
              validator: (value) {
                if (value == null || value.isEmpty) {
                  return 'Please enter your email';
                }
                return null;
              },
            ),
            TextButton(
              onPressed: () {
                if (_formKey.currentState!.validate()) {   // 3. ตรวจทุกช่อง
                  print('Form is valid');
                }
              },
              child: const Text('Save'),
            ),
          ],
        ),
      ),
    );
  }
}
3 ขั้นตอน: ① สร้าง GlobalKey<FormState> ② ใส่ key: _formKey ที่ Form ③ เรียก _formKey.currentState!.validate() ตอนกดปุ่ม (ได้ true เมื่อทุก validator คืน null)

4. TextEditingController

ใช้ดึงค่าจากช่องกรอก (.text) และกำหนด/ล้างค่าในช่องได้ ผูกผ่าน controller:

class _MyWidgetState extends State<MyWidget> {
  final _formKey = GlobalKey<FormState>();
  final TextEditingController _nameController = TextEditingController();

  @override
  void dispose() {
    _nameController.dispose();     // คืนทรัพยากรเมื่อไม่ใช้แล้ว
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Simple Form')),
      body: Form(
        key: _formKey,
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            TextFormField(
              controller: _nameController,              // ผูก controller
              decoration: const InputDecoration(labelText: 'Name'),
              validator: (value) {
                if (value == null || value.isEmpty) {
                  return 'Please enter your name';
                }
                return null;
              },
              onChanged: (value) {
                print(value);
              },
            ),
            TextButton(
              onPressed: () {
                print('User input: ${_nameController.text}');   // ดึงค่า
              },
              child: const Text('Save'),
            ),
          ],
        ),
      ),
    );
  }
}
💡 onChanged ได้ค่าทุกครั้งที่พิมพ์ · controller.text อ่านค่าตอนไหนก็ได้ (เช่น ตอนกดปุ่ม) · controller.clear() ล้างช่อง · ควร dispose() controller เมื่อปิดหน้า (ป้องกัน memory leak)

6. แบบฝึกหัด Form

ข้อ 1 — คำนวณ BMI

โจทย์: สร้างหน้า "คำนวณ BMI" ด้วย StatefulWidget + Form
1. GlobalKey<FormState> · TextFormField น้ำหนัก (kg) และส่วนสูง (cm) ตั้ง keyboardType: TextInputType.number
2. ทั้งสองช่องต้องมี validator — ถ้าว่างแสดง "กรุณากรอกข้อมูล"
3. ปุ่ม "คำนวณ BMI" → validate() ผ่านจึงคำนวณ · สูตร BMI = น้ำหนัก / (ส่วนสูง(m) × ส่วนสูง(m)) · ต้องแปลง cm → m ก่อน (÷100)
4. เก็บผลใน String result = "" แล้ว setState() แสดงใต้ปุ่ม เช่น "ค่า BMI ของคุณ คือ: 22.5"
Hint: ใช้ double.tryParse() ป้องกัน error ถ้าแปลงไม่ได้
ดูเฉลย (โค้ดเต็ม) 
import 'package:flutter/material.dart';

class BmiScreen extends StatefulWidget {
  const BmiScreen({super.key});

  @override
  State<BmiScreen> createState() => _BmiScreenState();
}

class _BmiScreenState extends State<BmiScreen> {
  final _formKey = GlobalKey<FormState>();
  final weightController = TextEditingController();
  final heightController = TextEditingController();
  String result = "";

  void calculate() {
    if (_formKey.currentState!.validate()) {
      final double? weight = double.tryParse(weightController.text);
      final double? heightCm = double.tryParse(heightController.text);
      if (weight == null || heightCm == null || heightCm == 0) return;

      final heightM = heightCm / 100;                 // cm → m
      final bmi = weight / (heightM * heightM);
      setState(() {
        result = 'ค่า BMI ของคุณ คือ: ${bmi.toStringAsFixed(1)}';
      });
    }
  }

  @override
  void dispose() {
    weightController.dispose();
    heightController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('คำนวณ BMI')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              TextFormField(
                controller: weightController,
                keyboardType: TextInputType.number,
                decoration: const InputDecoration(labelText: 'น้ำหนัก (kg)'),
                validator: (v) => (v == null || v.isEmpty) ? 'กรุณากรอกข้อมูล' : null,
              ),
              TextFormField(
                controller: heightController,
                keyboardType: TextInputType.number,
                decoration: const InputDecoration(labelText: 'ส่วนสูง (cm)'),
                validator: (v) => (v == null || v.isEmpty) ? 'กรุณากรอกข้อมูล' : null,
              ),
              const SizedBox(height: 16),
              ElevatedButton(onPressed: calculate, child: const Text('คำนวณ BMI')),
              const SizedBox(height: 16),
              Text(result, style: const TextStyle(fontSize: 20)),
            ],
          ),
        ),
      ),
    );
  }
}

ข้อ 2 — คำนวณค่าบริการล้างรถ

โจทย์: แอป "คำนวณค่าบริการล้างรถ"
1. GlobalKey<FormState> · ตัวแปร int _basePrice = 150;
2. DropdownButton<int> (หรือ Radio) เลือกขนาดรถ: รถเล็ก 150 · รถเก๋ง 200 · SUV/กระบะ 250 → เลือกแล้ว setState() อัปเดต _basePrice
3. bool _vacuum, bool _wax + CheckboxListTile "ดูดฝุ่น (+50)" และ "เคลือบแว็กซ์ (+100)"
4. ปุ่ม "คำนวณราคา": Total = _basePrice, ถ้า _vacuum → +50, ถ้า _wax → +100
5. แสดง "ราคารวม: $Total บาท" ตัวใหญ่ อัปเดตทุกครั้งที่ setState()
ดูเฉลย (โค้ดเต็ม) 
import 'package:flutter/material.dart';

class CarWashScreen extends StatefulWidget {
  const CarWashScreen({super.key});

  @override
  State<CarWashScreen> createState() => _CarWashScreenState();
}

class _CarWashScreenState extends State<CarWashScreen> {
  final _formKey = GlobalKey<FormState>();
  int _basePrice = 150;
  bool _vacuum = false;
  bool _wax = false;
  int _total = 150;

  void _calculate() {
    int total = _basePrice;
    if (_vacuum) total += 50;
    if (_wax) total += 100;
    setState(() {
      _total = total;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('ค่าบริการล้างรถ')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              DropdownButtonFormField<int>(
                value: _basePrice,
                decoration: const InputDecoration(labelText: 'ขนาดรถ'),
                items: const [
                  DropdownMenuItem(value: 150, child: Text('รถเล็ก (Small)')),
                  DropdownMenuItem(value: 200, child: Text('รถเก๋ง (Medium)')),
                  DropdownMenuItem(value: 250, child: Text('รถ SUV/กระบะ (Large)')),
                ],
                onChanged: (value) {
                  setState(() {
                    _basePrice = value!;
                  });
                },
              ),
              CheckboxListTile(
                title: const Text('ดูดฝุ่น (+50 บาท)'),
                value: _vacuum,
                onChanged: (v) => setState(() => _vacuum = v!),
              ),
              CheckboxListTile(
                title: const Text('เคลือบแว็กซ์ (+100 บาท)'),
                value: _wax,
                onChanged: (v) => setState(() => _wax = v!),
              ),
              ElevatedButton(onPressed: _calculate, child: const Text('คำนวณราคา')),
              const SizedBox(height: 16),
              Text('ราคารวม: $_total บาท',
                  style: const TextStyle(fontSize: 28, fontWeight: FontWeight.bold)),
            ],
          ),
        ),
      ),
    );
  }
}

7. API คืออะไร

API (Application Programming Interface) คือชุดกฎและโปรโตคอลที่กำหนดวิธีการสื่อสารระหว่างซอฟต์แวร์/ระบบต่าง ๆ ทำหน้าที่เป็นตัวกลางให้แอปแลกเปลี่ยนข้อมูลกันได้ โดยไม่ต้องรู้โครงสร้างภายในของกันและกัน

API ทำงานอย่างไร (4 ขั้นตอน)

  1. Client (ผู้ร้องขอ) → แอปของเราส่ง request ไปที่ API (เช่น ขอข้อมูลผู้ใช้)
  2. Server (ผู้ให้บริการ API) → ประมวลผล request และดึงข้อมูลจากฐานข้อมูล
  3. Response → API ส่งข้อมูลกลับมาเป็น JSON หรือ XML
  4. Client นำข้อมูลไปแสดงผล เช่น ใน ListView หรือ UI อื่น ๆ

RESTful API — HTTP Method

MethodCRUDความหมายStatus ที่คาดหวัง
GETReadขอ/ดึงข้อมูล200
POSTCreateสร้างข้อมูลใหม่201
PUTUpdateแก้ไขข้อมูล200
DELETEDeleteลบข้อมูล200
ทดสอบ GET ได้ง่าย ๆ โดยเปิด URL ใน Browser เช่น https://dummyjson.com/users/1 (Browser เรียกด้วย method GET)

ประโยชน์ของ API

  • เชื่อมแอปเข้าด้วยกัน เช่น Flutter App ↔ Backend (Node.js, FastAPI, Django)
  • ลดงานซ้ำซ้อน ใช้ API ของผู้ให้บริการ เช่น Google Maps, OpenWeather
  • ข้อมูลอัปเดตแบบ Real-time
  • รองรับการขยายแอป เพิ่มฟีเจอร์ได้ง่ายโดยใช้ API ระบบอื่น

8. JSON ใน Flutter (Dart)

JSON (JavaScript Object Notation) คือรูปแบบข้อมูลที่ใช้แลกเปลี่ยนระหว่างระบบ มีโครงสร้างแบบ Key–Value Pair อ่าน/เขียนง่าย 
{
  "id": 1,
  "firstName": "Emily",
  "username": "emilys",
  "email": "emily@example.com"
}

1) JSON → Dart (jsonDecode)

import 'dart:convert';

void main() {
  String jsonString = '{"name": "John Doe", "age": 25}';
  Map<String, dynamic> user = jsonDecode(jsonString);
  print(user['name']);   // John Doe
}

2) Dart → JSON (jsonEncode)

import 'dart:convert';

void main() {
  Map<String, dynamic> user = {"name": "Alice", "age": 22};
  String jsonString = jsonEncode(user);
  print(jsonString);     // {"name":"Alice","age":22}
}

3) JSON Array → List ของ Dart Object (Model Class)

import 'dart:convert';

// Model Class
class Student {
  final int id;
  final String name;

  Student(this.id, this.name);                 // Constructor

  Student.fromJson(Map<String, dynamic> json)  // JSON → Object
      : id = json['id'],
        name = json['name'];

  Map<String, dynamic> toJson() {              // Object → JSON Map
    return {'id': id, 'name': name};
  }
}

void main() {
  String jsonString = '''
  [
    {"id": 1, "name": "Alice"},
    {"id": 2, "name": "Bob"},
    {"id": 3, "name": "Charlie"}
  ]
  ''';

  // JSON String → List ของ Object
  List<dynamic> jsonList = jsonDecode(jsonString);
  List<Student> students = jsonList.map((item) => Student.fromJson(item)).toList();

  for (var student in students) {
    print("ID: ${student.id}, Name: ${student.name}");
  }

  // Object → JSON Array
  String newJsonString = jsonEncode(students.map((e) => e.toJson()).toList());
  print("JSON ใหม่: $newJsonString");
}
สรุป: jsonDecode() แปลง String → Map/List · jsonEncode() แปลง Map/List → String · fromJson / toJson คือ method ที่เราเขียนเองใน Model Class

9. แพ็กเกจ http เรียก API

ใน Flutter มีแพ็กเกจเชื่อมต่อ API บน pub.dev ที่นิยมคือ http (เรียก API ทั่วไป) และ dio (โปรเจกต์ซับซ้อนขึ้น)

# ติดตั้ง (terminal)
flutter pub add http

# หรือเพิ่มใน pubspec.yaml แล้ว flutter pub get
dependencies:
  http: ^1.2.0
import 'package:http/http.dart' as http;
import 'dart:convert';

void main() {
  void fetchUser() async {
    try {
      var response = await http.get(Uri.parse('https://dummyjson.com/users/1'));
      if (response.statusCode == 200) {                 // 200 = สำเร็จ
        var data = jsonDecode(response.body);           // body เป็น String JSON
        print('Name: ${data["firstName"]}');
      } else {
        print('Failed to fetch data');
      }
    } catch (e) {
      print('Error: $e');                               // เช่น ไม่มีอินเทอร์เน็ต
    }
  }

  fetchUser();
}
องค์ประกอบ:
  • async / await — รอผลจากเครือข่ายโดยไม่ค้างหน้าจอ
  • Uri.parse('url') — แปลง String เป็น Uri
  • response.statusCode — รหัสผลลัพธ์ (200 = OK) · response.body — ข้อมูลที่ได้ (String)
  • try / catch — ดักข้อผิดพลาด

แบบใช้ Model Class

class User {
  final int id;
  final String firstName;
  final String username;
  final String email;

  User(this.id, this.firstName, this.username, this.email);

  User.fromJson(Map<String, dynamic> json)
      : id = json['id'],
        firstName = json['firstName'],
        username = json['username'],
        email = json['email'];

  Map<String, dynamic> toJson() {
    return {'id': id, 'firstName': firstName, 'username': username, 'email': email};
  }
}

// ---------- model/user_data.dart ----------
class User {
  final int id;
  final String firstName;
  final String lastName;
  final String username;
  final String email;

  User({
    required this.id,
    required this.firstName,
    required this.lastName,
    required this.username,
    required this.email,
  });

  String get fullName => '$firstName $lastName';

  factory User.fromJson(Map<String, dynamic> json) {
    return User(
      id: json['id'],
      firstName: json['firstName'],
      lastName: json['lastName'],
      username: json['username'],
      email: json['email'],
    );
  }
}

// ---------- list_user_screen.dart ----------
import 'dart:convert';
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;

class ListUserScreen extends StatefulWidget {
  const ListUserScreen({super.key});

  @override
  State<ListUserScreen> createState() => _ListUserScreenState();
}

class _ListUserScreenState extends State<ListUserScreen> {
  List<User> listUser = [];

  @override
  void initState() {
    super.initState();
    getUser();                                   // โหลดตอนเปิดหน้า
  }

  Future<void> getUser() async {
    try {
      var response = await http.get(Uri.parse('https://dummyjson.com/users'));
      if (response.statusCode == 200) {
        var data = jsonDecode(response.body);
        List<dynamic> jsonList = data['users'];  // ดึง Array จาก key users
        setState(() {
          listUser = jsonList.map((item) => User.fromJson(item)).toList();
        });
      }
    } catch (e) {
      print('Error : $e');
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Call API')),
      body: ListView.separated(
        itemCount: listUser.length,
        separatorBuilder: (BuildContext context, int index) => const Divider(),
        itemBuilder: (BuildContext context, int index) {
          return ListTile(
            leading: Text('ID ${listUser[index].id}'),
            title: Text(listUser[index].fullName),
            subtitle: Text(listUser[index].email),
          );
        },
      ),
      floatingActionButton: ElevatedButton(
        onPressed: () {
          getUser();                             // กดเพื่อโหลดใหม่
        },
        child: const Text('refresh'),
      ),
    );
  }
}
⚠️ จุดที่ผิดบ่อย: เรียก getUser() ใน initState() (ห้ามทำ initState เป็น async) · ต้อง setState() หลังได้ข้อมูล ไม่งั้น ListView ไม่อัปเดต · endpoint ต้องเป็น /users (ตัวอย่าง "fix api endpoint" ในไฟล์ของอาจารย์แก้จาก /user ที่พิมพ์ผิด)

import 'dart:convert';
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;

class AqiScreen extends StatefulWidget {
  const AqiScreen({super.key});

  @override
  State<AqiScreen> createState() => _AqiScreenState();
}

class _AqiScreenState extends State<AqiScreen> {
  int aqi = 0;
  String city = '-';
  double temp = 0;

  // ใส่ URL ที่ได้จากหน้าขอ Token (มี token ของตัวเอง)
  final String url = 'YOUR_AQICN_API_URL_WITH_TOKEN';

  @override
  void initState() {
    super.initState();
    fetchAqi();
  }

  Future<void> fetchAqi() async {
    try {
      var response = await http.get(Uri.parse(url));
      if (response.statusCode == 200) {
        var res = jsonDecode(response.body);
        setState(() {
          aqi = int.tryParse(res['data']['aqi'].toString()) ?? 0;   // data.aqi
          city = res['data']['city']['name'];                        // data.city.name
          temp = (res['data']['iaqi']['t']['v'] as num).toDouble();  // data.iaqi.t.v
        });
      }
    } catch (e) {
      print('Error: $e');
    }
  }

  // เงื่อนไขสีและข้อความตามระดับ AQI
  Color get aqiColor {
    if (aqi <= 50) return Colors.green;
    if (aqi <= 100) return Colors.yellow;
    if (aqi <= 150) return Colors.orange;
    if (aqi <= 200) return Colors.red;
    if (aqi <= 300) return Colors.purple;
    return Colors.brown;
  }

  String get aqiText {
    if (aqi <= 50) return 'Good';
    if (aqi <= 100) return 'Moderate';
    if (aqi <= 150) return 'Unhealthy for Sensitive Groups';
    if (aqi <= 200) return 'Unhealthy';
    if (aqi <= 300) return 'Very Unhealthy';
    return 'Hazardous';
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Air Quality')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(city, style: const TextStyle(fontSize: 24)),
            const SizedBox(height: 12),
            Container(
              padding: const EdgeInsets.all(24),
              color: aqiColor,
              child: Text('AQI $aqi', style: const TextStyle(fontSize: 40)),
            ),
            Text(aqiText),
            const SizedBox(height: 12),
            Text('Temperature: $temp °C', style: const TextStyle(fontSize: 20)),
          ],
        ),
      ),
    );
  }
}

อัตนัย (ตัวอย่างคำตอบ)

1. อธิบายหน้าที่ของ Form, TextFormField และ GlobalKey<FormState>

Form เป็นตัวจัดการฟอร์มที่ครอบช่องกรอกหลายช่อง · TextFormField คือช่องกรอกข้อความที่มี validator ตรวจสอบค่า · GlobalKey<FormState> ผูกกับ Form เพื่อเรียก validate() ตรวจทุกช่อง และ save() บันทึกค่า

2. API คืออะไร และทำงานอย่างไร

API คือชุดกฎ/โปรโตคอลให้ซอฟต์แวร์ต่างระบบสื่อสารและแลกเปลี่ยนข้อมูลกันได้โดยไม่ต้องรู้โครงสร้างภายใน ทำงาน 4 ขั้น: Client ส่ง request → Server ประมวลผลและดึงข้อมูลจาก DB → ส่ง response (JSON/XML) กลับ → Client นำไปแสดงผล เช่นใน ListView

3. อธิบายความแตกต่างของ jsonDecode, jsonEncode, fromJson และ toJson

jsonDecode แปลง JSON String → Map/List · jsonEncode แปลง Map/List → JSON String · fromJson (เขียนเองใน Model) แปลง Map → Object · toJson แปลง Object → Map

4. เขียนโค้ดเรียก GET จาก https://dummyjson.com/users/1 แล้วพิมพ์ firstName 
var response = await http.get(Uri.parse('https://dummyjson.com/users/1'));
if (response.statusCode == 200) {

}
