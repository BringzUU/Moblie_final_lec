5. Null Safety

null = "ไม่มีค่าเลย" (ไม่ใช่ 0, ไม่ใช่ false, ไม่ใช่ string ว่าง)
Null Safety = ฟีเจอร์ป้องกัน error จากการเรียกใช้ตัวแปรที่เป็น null (null dereference error ทำให้แอปพังตอนรัน) ตั้งแต่ Dart 2.12 ตัวแปรจะเป็น null ไม่ได้โดยอัตโนมัติ เว้นแต่ระบุว่าอนุญาต
String? name;            // Nullable type: ใส่ ? ต่อท้ายชนิด เก็บ null ได้
name = null;

print(name ?? 'ไม่มีชื่อ');   // ?? ถ้า null ใช้ค่าหลัง ??
name ??= 'Guest';          // ??= กำหนดค่าเฉพาะตอนที่ยังเป็น null
print(name?.length);          // ?. เรียกใช้เมื่อไม่เป็น null (ไม่งั้นได้ null)
print(name!.length);          // ! ยืนยันว่าไม่ null (ถ้าผิดจะ error ตอนรัน)
เครื่องหมายชื่อความหมาย
??if-nullกำหนดค่าเริ่มต้นหากเป็น null
??=null-aware assignmentกำหนดค่าหากตัวแปรเป็น null อยู่
?.null-aware accessเรียกใช้เมื่อไม่เป็น null
!null assertionยืนยันว่าไม่ null (ผิดแล้ว error ตอนรัน)

8. Class, Object, Inheritance

class Student {
  int id;
  String name;
  double score;

  Student(this.id, this.name, this.score);       // Parameter constructor
  Student.empty() : id = 0, name = '', score = 0;  // Named constructor

  void showInfo() => print('$id $name $score');
}

void main() {
  var s1 = Student(1, 'Anna', 80);
  s1.showInfo();
  var s2 = Student.empty();
}
กฎตั้งชื่อ: Class = UpperCamelCase (StudentProfile) / object, property, method = lowerCamelCase (totalScore)
Constructor: ชื่อเหมือน class, ไม่ระบุ return type, ทำงานอัตโนมัติตอนสร้าง object, เรียกเหมือน method ทั่วไปไม่ได้
this: อ้างถึง property/method ของ object ปัจจุบัน (ใช้เมื่อชื่อ parameter ซ้ำกับ property)

Encapsulation, Getter/Setter, static

class Account {
  double _balance = 0;                 // _ นำหน้า = private ใน library
  double get balance => _balance;        // Getter: อ่านค่า
  set balance(double v) {              // Setter: ตั้งค่า + ตรวจสอบได้
    if (v >= 0) _balance = v;
  }
  static int count = 0;                 // static: เป็นของ class ไม่ใช่ของ object
  static void hello() => print('hi');
}
// เรียก: Account.count, Account.hello()  (ไม่ต้องสร้าง object)
Encapsulation = รวมข้อมูลและพฤติกรรมไว้ใน Class ซ่อนรายละเอียดภายใน เปิดให้ใช้ผ่าน Method/Getter/Setter ช่วยลดผลกระทบเมื่อโครงสร้างเปลี่ยน และตรวจข้อมูลก่อนแก้ไข
_ เป็น private ระดับ Library (ไฟล์) ไม่ใช่ระดับ Class

Lab ตัวอย่าง: จัดการข้อมูลนักศึกษา

class Student {
  final int id; final String name; final double score;
  Student(this.id, this.name, this.score);
}
double average(List<Student> list) =>
    list.map((s) => s.score).reduce((a, b) => a + b) / list.length;

void main() {
  var students = [
    Student(1, 'A', 80), Student(2, 'B', 55), Student(3, 'C', 70),
    Student(4, 'D', 65), Student(5, 'E', 40),
  ];
  var pass  = students.where((s) => s.score >= 60);       // กรองคะแนน ≥ 60
  var names = pass.map((s) => s.name).toList();            // ['A','C','D']
  print(names);
  print(average(students));                                 // 62.0
}

9. ฝึกทำข้อสอบ

ปรนัย (กดดูเฉลย)

1. ข้อใดคือชื่อตัวแปรที่ถูกต้องใน Dart? ก. 2name ข. my name ค. _total ง. class

ตอบ ค. ขึ้นต้นด้วย _ ได้ ส่วน ก. ขึ้นต้นด้วยเลข ข. มีช่องว่าง ง. เป็น keyword

2. โค้ดใดทำงานอย่างน้อย 1 ครั้งเสมอ? ก. while ข. for ค. do...while ง. if

ตอบ ค. do...while ทำก่อนแล้วค่อยตรวจเงื่อนไข

3. where() คืนค่าชนิดใด?

ตอบ Iterable<T> ต้องเรียก .toList() ถ้าต้องการ List

4. name ??= 'Guest' ทำอะไร?

ตอบ กำหนดค่า 'Guest' ให้ name เฉพาะตอนที่ name เป็น null อยู่

5. Collection ชนิดใดห้ามมีข้อมูลซ้ำ? ก. List ข. Set ค. Map(value) ง. ถูกทั้ง ข และ key ของ Map

ตอบ ง. Set ห้ามสมาชิกซ้ำ และ Map ห้าม key ซ้ำ (value ซ้ำได้)

6. int x = null; ผิดเพราะอะไร?

ตอบ Null Safety ทำให้ int เป็น null ไม่ได้ ต้องเขียน int? x = null;

7. ข้อใดไม่ใช่คุณสมบัติของ Constructor? ก. ชื่อเหมือน class ข. ไม่มี return type ค. เรียกใช้เหมือน method ทั่วไป ง. ทำงานตอนสร้าง object

ตอบ ค. Constructor ทำงานอัตโนมัติตอนสร้าง object เรียกเหมือน method ทั่วไปไม่ได้

อัตนัย (ตัวอย่างคำตอบ)

1. Native และ Cross-platform ต่างกันอย่างไร?

Native พัฒนาแยกตามระบบปฏิบัติการด้วยภาษา/เครื่องมือของระบบนั้น (Android: Kotlin/Java + Android Studio, iOS: Swift/Objective-C + Xcode) ต้องเขียนหลายชุดโค้ด ส่วน Cross-platform เขียนโค้ดชุดเดียวแล้วใช้ได้ทั้ง Android และ iOS (เช่น Flutter, React Native, .NET MAUI)

2. final และ const ต่างกันอย่างไร?

ทั้งคู่เปลี่ยนค่าไม่ได้หลังกำหนด และต้องกำหนดค่าตอนประกาศ final ค่าถูกกำหนดตอนรันโปรแกรม (runtime) ส่วน const ต้องเป็นค่าที่ทราบตั้งแต่ตอน compile

3. Null Safety ป้องกันปัญหาอะไร? ยกตัวอย่างเครื่องหมายที่เกี่ยวข้อง 3 ตัว

ป้องกัน error จากการเรียกใช้ตัวแปรที่เป็น null (null dereference) ซึ่งทำให้แอปพังตอนรัน เช่น ? (nullable type), ?? (if-null), ?. (null-aware access), ??=, !

4. List, Set และ Map ต่างกันอย่างไร?

List เก็บข้อมูลแบบมีลำดับ มี index เริ่ม 0 ซ้ำได้ / Set เก็บข้อมูลที่ห้ามซ้ำ / Map เก็บเป็นคู่ key-value โดย key ห้ามซ้ำ

5. extends และ @override ทำหน้าที่อะไร? ยกตัวอย่างใน Flutter

extends สร้าง class ใหม่จาก class เดิม (สืบทอด) ส่วน @override บอกว่า method นี้เขียนทับ method ของ parent เช่น class MyApp extends StatelessWidget และ @override Widget build(BuildContext context)

6. เขียนโค้ด: กรองคะแนนที่ ≥ 60 จาก [45, 60, 82, 30] แล้วพิมพ์ผล
var pass = [45, 60, 82, 30].where((s) => s >= 60).toList();
print(pass);  // [60, 82]
