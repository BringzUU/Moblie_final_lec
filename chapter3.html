บทที่ 3: Navigation

การเปลี่ยนหน้าจอ: Navigator, Named Routes, การส่งข้อมูลระหว่างหน้า, Bottom Navigation Bar

Navigation คืออะไร Stack: Push / Pop แบบพื้นฐาน โจทย์ Named Routes ส่งข้อมูล รับค่ากลับ Bottom Nav Bar ทวนก่อนสอบ

1. Navigation คืออะไร

Navigation คือกระบวนการเปลี่ยนหน้าจอ (Screens/Pages) ภายในแอป ให้ผู้ใช้ไปดูข้อมูลหรือทำงานเพิ่มเติมในหน้าอื่นได้ โดยอาศัย Navigator Widget ซึ่งทำหน้าที่เป็นตัวจัดการ Stack ของหน้าจอ

ใน Flutter หน้าจอ (screen) เรียกว่า Route ตัวอย่างในสไลด์: First Route (ปุ่ม Open route) → Second Route (ปุ่ม Go back!)

ประเภท Navigation ในบทนี้สรุป
แบบพื้นฐานใช้ Navigator + MaterialPageRoute เหมาะกับแอปง่าย ๆ หน้าจอไม่ซับซ้อน
Named Routesตั้งชื่อ (String) ให้ route ใช้ pushNamed เหมาะกับแอปหลายหน้า / Flutter web
Bottom Navigation Barเมนูด้านล่างสลับหน้าหลัก เช่น Home, Search, Profile

2. Navigator = Stack (กองกระดาษ)

  • Push — เพิ่มหน้าจอใหม่ไว้ด้านบนสุดของ Stack
  • Pop — ย้อนกลับ ลบหน้าจอบนสุดออก
  • หน้าที่เห็นบนจอ = หน้าบนสุดของ Stack

3. Navigation แบบพื้นฐาน

Push — ไปหน้าใหม่

Navigator.push(
  context,
  MaterialPageRoute(builder: (context) => const SecondRoute()),
);

Pop — ย้อนกลับ

Navigator.pop(context);
องค์ประกอบ
  • Navigator.push(context, route) — เพิ่มหน้าใหม่
  • MaterialPageRoute — route แบบ Material ที่มี animation เปลี่ยนหน้า
  • builder: (context) => ... — ฟังก์ชันที่คืน Widget ของหน้าปลายทาง
  • Navigator.pop(context) — ลบหน้าบนสุดออก ย้อนกลับหน้าก่อนหน้า

4. โจทย์: Navigation แบบพื้นฐาน

1. สร้าง 2 หน้าจอ ใช้ StatelessWidget
2. หน้าแรก: ปุ่มกลางจอ นำทางไปหน้าที่สอง
3. หน้าที่สอง: ปุ่มกลางจอ กลับไปหน้าแรก
ดูเฉลย (โค้ดเต็ม) 
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(
    title: 'Navigation Basics',
    home: FirstRoute(),
  ));
}

class FirstRoute extends StatelessWidget {
  const FirstRoute({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('First Route')),
      body: Center(
        child: ElevatedButton(
          child: const Text('Open route'),
          onPressed: () {
            Navigator.push(
              context,
              MaterialPageRoute(builder: (context) => const SecondRoute()),
            );
          },
        ),
      ),
    );
  }
}

class SecondRoute extends StatelessWidget {
  const SecondRoute({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Second Route')),
      body: Center(
        child: ElevatedButton(
          onPressed: () {
            Navigator.pop(context);
          },
          child: const Text('Go back!'),
        ),
      ),
    );
  }
}
💡 หน้าที่สองมี ปุ่มลูกศรย้อนกลับ ← บน AppBar อัตโนมัติ (Flutter ใส่ให้เมื่อมีหน้าก่อนหน้าใน Stack) กดแล้วทำงานเหมือน pop

5. Named Routes

กำหนดเส้นทางด้วยชื่อ (String) แทนการสร้าง MaterialPageRoute ทุกครั้งที่เปลี่ยนหน้า เหมาะกับแอปที่มีหลายหน้าจอ หรือทำ Flutter web

  1. กำหนด Map ของ route ใน MaterialApp (routes) พร้อม initialRoute
  2. ไปหน้าใหม่ด้วย Navigator.pushNamed(context, '/ชื่อ')
  3. ย้อนกลับด้วย Navigator.pop(context) (เหมือนแบบพื้นฐาน)
void main() {
  runApp(MaterialApp(
    title: 'Named Routes',
    initialRoute: '/',                       // หน้าแรกของแอป
    routes: {
      '/': (context) => const FirstScreen(),
      '/second': (context) => const SecondScreen(),
    },
  ));
}

// ไปหน้า /second
ElevatedButton(
  onPressed: () {
    Navigator.pushNamed(context, '/second');
  },
  child: const Text('Launch screen'),
)

// ย้อนกลับ
ElevatedButton(
  onPressed: () {
    Navigator.pop(context);
  },
  child: const Text('Go back!'),
)
แบบพื้นฐานNamed Routes
ไปหน้าใหม่Navigator.push(context, MaterialPageRoute(...))Navigator.pushNamed(context, '/path')
กำหนด routeใส่ใน builder ทุกครั้งที่ pushกำหนดครั้งเดียวใน routes ของ MaterialApp
ย้อนกลับNavigator.pop(context) เหมือนกัน
เหมาะกับแอปง่าย หน้าน้อยแอปหลายหน้า, Flutter web
⚠️ ถ้ากำหนด home: แล้วอย่าใส่ route '/' ซ้ำใน routes (จะ error) — ถ้าใช้ routes ให้ใช้ initialRoute แทน home

6. ส่งข้อมูลระหว่างหน้าจอ (Passing Data)

ช่วยให้หน้าต่าง ๆ สื่อสารกันได้ — ส่งไปหน้าถัดไป และรับค่ากลับจากหน้านั้นได้

วิธีหลัก: ส่งผ่าน Constructor (arguments ของ Widget)

  1. ปลายทางสร้าง Constructor รับค่า (ตัวแปร final + required)
  2. ต้นทางส่งค่าตอนสร้าง Widget ใน MaterialPageRoute
// หน้าปลายทาง: รับค่าผ่าน Constructor
class DetailScreen extends StatelessWidget {
  final String title;
  final int id;

  const DetailScreen({super.key, required this.title, required this.id});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(title)),
      body: Center(child: Text('ID: $id')),
    );
  }
}

// หน้าต้นทาง: ส่งค่าตอน push
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (context) => const DetailScreen(title: 'สินค้า A', id: 101),
  ),
);

ตัวอย่าง: ส่งข้อมูลจาก ListView ไปหน้ารายละเอียด

ListView.builder(
  itemCount: items.length,
  itemBuilder: (context, index) {
    return ListTile(
      title: Text(items[index]),
      onTap: () {
        Navigator.push(
          context,
          MaterialPageRoute(
            builder: (context) => DetailScreen(title: items[index], id: index),
          ),
        );
      },
    );
  },
)

เสริม: ส่งผ่าน Named Route ด้วย arguments

// ส่ง
Navigator.pushNamed(context, '/detail', arguments: 'Hello');

// รับ (ในหน้าปลายทาง)
final msg = ModalRoute.of(context)!.settings.arguments as String;

7. รับค่ากลับจากหน้าที่สอง

ส่งค่ากลับด้วยการใส่ผลลัพธ์ใน pop และรับด้วย await ที่ push

// หน้าแรก: await รอผลลัพธ์
onPressed: () async {
  final result = await Navigator.push(
    context,
    MaterialPageRoute(builder: (context) => const SelectScreen()),
  );
  print(result);               // 'Yes'
},

// หน้าที่สอง: pop พร้อมค่า
onPressed: () {
  Navigator.pop(context, 'Yes');
},

8. Bottom Navigation Bar

Widget เมนูด้านล่างจอ ช่วยสลับระหว่างหน้าหลักของแอป เช่น Home, Search, Profile ใส่ใน Scaffold ที่ bottomNavigationBar และต้องใช้ StatefulWidget เพราะต้องจำว่าเลือกแท็บไหนอยู่

องค์ประกอบสำคัญ
  • currentIndex — ตำแหน่งแท็บที่เลือกอยู่ (State)
  • onTap: (index) { setState(...) } — เมื่อกดแท็บ ให้เปลี่ยน index
  • items: [BottomNavigationBarItem(icon:, label:)] — รายการแท็บ (อย่างน้อย 2 อัน)
  • เก็บหน้าไว้ใน List<Widget> แล้วแสดง _pages[_currentIndex] ที่ body
import 'package:flutter/material.dart';

class MainScreen extends StatefulWidget {
  const MainScreen({super.key});

  @override
  State<MainScreen> createState() => _MainScreenState();
}

class _MainScreenState extends State<MainScreen> {
  int _currentIndex = 0;                    // แท็บที่เลือกอยู่

  final List<Widget> _pages = const [
    Center(child: Text('Home Page')),
    Center(child: Text('Search Page')),
    Center(child: Text('Profile Page')),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Bottom Navigation')),
      body: _pages[_currentIndex],          // แสดงหน้าตาม index
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _currentIndex,
        onTap: (index) {
          setState(() {
            _currentIndex = index;          // เปลี่ยนแท็บ
          });
        },
        items: const [
          BottomNavigationBarItem(icon: Icon(Icons.home), label: 'Home'),
          BottomNavigationBarItem(icon: Icon(Icons.search), label: 'Search'),
          BottomNavigationBarItem(icon: Icon(Icons.person), label: 'Profile'),
        ],
      ),
    );
  }
}
💡 ถ้ามีแท็บ 4 อันขึ้นไป ต้องตั้ง type: BottomNavigationBarType.fixed ไม่งั้นแท็บจะเป็นแบบ shifting และสีอาจเพี้ยน
